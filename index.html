Accessible by design

Made for every mind and every eye.

Memory changes often come with vision and hearing changes. ReMind can read every page and question aloud, highlighting each line as it goes.

  • Read aloud with follow-along highlight
  • Text up to 160% larger
  • High-contrast mode
  • Large buttons and keyboard shortcuts

ReMind is a screening tool, not a diagnosis. It does not replace a doctor. If you are worried about memory changes, talk to a healthcare professional.
